# Política de nomes e marcas

O código do Teko é livre sob a [AGPL 3.0](LICENSE). Os **nomes não são**.

As marcas abaixo pertencem a Felipe Oliveira (Teki Industries):

- Teko
- Teki e Teki Industries
- Cofu
- Os logotipos, ícones e identidade visual desses projetos

A AGPL 3.0, seção 7(e), permite recusar direitos sobre marcas. É o que este projeto faz: a licença do código não dá permissão pra usar esses nomes.

## Pode, sem pedir

- Dizer a verdade sobre de onde veio: "baseado no Teko", "fork do Teko", "compatível com o Teko"
- Falar do projeto em artigo, vídeo, aula, palestra ou review
- Usar o nome sem mudança pra se referir ao projeto oficial

## Não pode, sem autorização por escrito

- Publicar fork, produto ou serviço com esses nomes ou parecidos: "Teko Pro", "Teko+", "TekoAI", "Cofu Lite", "Teki Cloud"
- Usar os logotipos ou a identidade visual num projeto derivado
- Dar a entender que um fork é oficial, apoiado ou certificado pelo autor
- Registrar domínio, @ ou empresa com esses nomes pra se passar pelo projeto

## Se você fizer um fork

1. Escolha outro nome
2. Troque os logotipos
3. Mantenha o crédito ao autor original e o [NOTICE](NOTICE), como a AGPL exige

Dúvidas ou pedido de autorização: [@tekiidev](https://github.com/tekiidev).
